## Skill Usage

### Project-Plan-Manager skill
Gunakan setiap kali user meminta informasi mengenai Plan, atau meminta eksekusi Plan

### Project-Documentations-Manager skill
Gunakan setiap kali: 
- user meminta informasi dasar tentang projek, fitur, usecase, atau membuat fitur baru
- sedang melakukan explorasi kode untuk memahami suatu fitur
- membuat, menghapus, atau merubah file kode didalam projek

Plugin authoring guide (manifest, capabilities, permissions, hooks, graphs, CLI, publishing): `.docs/plugin-authoring.md`
